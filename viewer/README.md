# Screen Viewer Application — Stage 6

This module is planned for implementation in **Stage 6**.

## Planned Architecture & Components:
1. Desktop application (Tauri / Electron) or responsive Web UI.
2. Direct connection to the WebSocket / WebRTC streaming feed.
3. Telemetry indicators: FPS, resolution, round-trip latency, connection state.
4. Stream controls ("Connect", "Pause", "Emergency Stop").
